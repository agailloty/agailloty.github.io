L'asynchronie : .NET 10 → .NET 11

La même méthode async Task Main() — deux stratégies d'exécution

Méthode initiale — ce que vous écrivez

public static async Task Main()
{
    await DoTaskAsynchronously();
}

private static async Task DoTaskAsynchronously()
{
    await Task.Run(() => 5 + 1);
}

.NET 11 Runtime Async

Le CLR suspend et reprend la méthode nativement

1
Appel de Main — méthode réelle
13 octets d'IL linéaire, aucun code généré.
Task task = DoTaskAsynchronously();
2
Suspension via AsyncHelpers
L'appel encapsule le point d'await ; le CLR sauvegarde l'état de la méthode.
AsyncHelpers.Await(task);
3
Reprise native
Le runtime restaure la méthode et poursuit — pas de machine à états, pas de try/catch généré.
